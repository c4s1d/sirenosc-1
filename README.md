# SirenOsc - Android project

Generated by the SirenOsc APK converter. The web app lives in app/src/main/assets/www/ and is served
from inside the APK (no browser, no network needed except optional Google Fonts on first launch).

## What was set up
- Mobile layout is ON by default (seeded into sirenosc_ui_settings on first launch only - the user can still switch it in Preferences).
- High-performance mode: page started with ?fps=60 (removes the 30 fps visual cap and low-power throttling).
- Hardware-accelerated WebView, uncompressed assets, Safe Browsing off, no zoom/overscroll, activity survives rotation without reloading.
- Highest refresh rate at native resolution + sustained-performance mode requested.
- Web Audio latency hint: balanced.
- Audio keeps playing with the screen off / app in background (foreground service + wake lock, only while sound is running; notification has a Quit button).
- Screen stays on while the app is open.
- Immersive fullscreen (swipe from an edge to show system bars).
- Exports / recordings / presets saved from the app go to Downloads/SirenOsc (blob downloads are bridged to native storage).
- Loading presets / audio files from the device uses the native file picker.
- External links open in the system browser.

## Build the APK (pick one)

### A) GitHub Actions - no local install
1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the Actions tab -> "Build APK" -> Run workflow (it also runs on every push).
3. When it finishes, download the "SirenOsc-apk" artifact. Unzip it -> app-release.apk.

### B) Android Studio
Open this folder -> let Gradle sync -> Build > Build Bundle(s) / APK(s) > Build APK(s).
Output: app/build/outputs/apk/release/app-release.apk

### C) Command line (needs JDK 17 + Android SDK, ANDROID_HOME set)
    ./gradlew assembleRelease

## Install
Copy the APK to the phone, open it, allow "install unknown apps" when asked. Android 10+ required (minSdk 29).

## Signing
The APK is signed with app/release.keystore (alias/password: sirenosc). It is bundled so updates install over
older builds. It is not secret - for a Play Store release replace it with your own keystore.

## Updating the app
Re-run the converter on the new zip and replace this project's assets/www folder (or the whole project).
Keep versionCode in app/build.gradle increasing so Android accepts the update.
